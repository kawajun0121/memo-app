# メモ

「思いついた瞬間に雑に放り込めて、必要になったら簡単に整理・検索できる」ことを目的にした、個人用の高速メモアプリです。インストール不要・ビルド不要で動きます。

## 使い方

### PCで使う

[index.html](index.html) をブラウザ（Edge / Chrome など）でダブルクリックして開くだけです。サーバーやNode.jsのインストールは不要です。

### iPhoneで使う

GitHub Pagesで公開したURL（例: `https://ユーザー名.github.io/memo-app/`）をSafariで開き、共有ボタン→「ホーム画面に追加」でアプリのように使えます。画面幅に応じて自動でレイアウトが切り替わり、狭い画面では一覧⇄本文が1画面ずつの表示になります。

データはIndexedDB（ブラウザ内蔵のデータベース）に保存されます。**同じブラウザ／同じホーム画面アプリを開いたときだけ**以前のデータが復元されます。PC・iPhoneなど複数端末でデータを共有したい場合は、下記の「クラウド同期（Firebase）」を使ってログインしてください。ログインしない場合は各端末に別々にデータが保存されます（「同期せずこの端末だけで使う」）。

### クラウド同期（Firebase・任意）

左サイドバー上部の⚙（設定）→「ログイン / 新規登録」から、メールアドレスとパスワードでアカウントを作成・ログインすると、同じアカウントでログインした端末同士でメモ・カテゴリ・種類・スマートビューが同期されます（編集履歴は同期されず、各端末にローカルで保持されます）。`src/firebaseConfig.js` にFirebaseプロジェクトの設定値があります。別のFirebaseプロジェクトを使う場合はここを書き換え、Firebase Console側でメールアドレス/パスワード認証を有効にし、Firestoreのセキュリティルールを以下のようにしてください。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/data/{document} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

同期は「同時編集の内容は更新日時が新しい方を優先」「完全削除した項目が復活することがある」という簡易的な仕組みです（個人の1〜2台での利用を想定）。

### iPhoneのホーム画面アプリが更新されない場合

iPhoneのホーム画面に追加したアプリは、Safariのタブとは別の独立したキャッシュ領域を持っており、Safari側を更新してもホーム画面アプリには自動反映されないことがあります。反映されない場合は、ホーム画面アプリのアイコンを削除し、Safariで開き直してから「ホーム画面に追加」をやり直してください。

## 技術構成と、当初案からの変更点

このアプリは元々 Next.js + TypeScript + React + Prisma + SQLite 構成で計画されましたが、開発・動作確認を行ったPCに **Node.jsがインストールされていなかった** ため、以下の構成に変更しました（本アプリはビルドなしでそのまま動く必要があるため）。

| 項目 | 当初案 | 採用した構成 | 理由 |
|---|---|---|---|
| 実行方式 | Next.js（要Node.jsサーバー） | ビルド不要のバニラJavaScript（classicスクリプト＋グローバル名前空間） | Node.js非依存で`index.html`をダブルクリックするだけで動かすため |
| 型付け | TypeScript | JSDoc + `jsconfig.json`（`checkJs`） | tscの実行にもNode.jsが必要なため。エディタ上の型チェックは有効 |
| データベース | SQLite + Prisma | IndexedDB（ブラウザ内蔵） | サーバー・ビルドなしで永続化でき、1万件規模でも実用速度が出るため |
| UIライブラリ | shadcn/ui | 自前のCSS（クラスベース） | npmが使えないため。依存パッケージは0 |
| AI APIキー管理 | `.env` + サーバー経由 | 設定画面でAnthropic APIキーをブラウザに保存し、直接API呼び出し | サーバーが無いため`.env`は使えない。キーはこの端末のブラウザ内にのみ保存され、コード・Gitには一切含まれない |

検索・絞り込み・並び替えは、起動時に全メモをメモリ上に読み込み、配列操作でリアルタイムに行っています。一覧表示は仮想スクロール（見えている行だけHTMLを生成）にしているため、メモが1,000〜1万件規模になっても軽快に動作します。

なお、当初はPWA（Service Worker）でオフライン起動にも対応していましたが、iPhoneのホーム画面アプリがキャッシュを更新に追従させにくいという問題があったため廃止し、常にネットワークから最新版を読み込む方式にしています（`sw.js`は過去にインストールされたService Workerを解除する後片付け用として残しています）。メモのデータ自体はIndexedDBに保存されるため、一度アプリを開いていればオフラインでも問題なく読み書きできます。

## ディレクトリ構成

```
index.html              アプリ本体（これを開く）
src/
  types/typedefs.js     データ構造の説明（JSDoc）
  logic/                 純粋なロジック（絞り込み・並び替え・履歴保存ポリシー等）
  db/                    IndexedDB / localStorageへの永続化
  store/                 メモリ上の状態管理（メモ・カテゴリ・種類・UI状態等）
  ai/                    AIカテゴリ提案（Anthropic API呼び出し）
  render/                 画面の見た目（HTML組み立て・イベント処理）
  styles/                 CSS（デザイン）
tests/
  logic.test.html         logic層の自動テスト（ブラウザで開くだけで実行される）
```

## AIカテゴリ提案機能を使うには（任意）

1. 左サイドバー上部の⚙（設定）を開く
2. Anthropic APIキー（`sk-ant-...`）を入力して保存
3. メモを開き、「AIカテゴリ提案」ボタンを押す

APIキーを設定しなくても、メモの作成・編集・検索・整理などの基本機能はすべて問題なく使えます。AIは既存カテゴリを最優先して提案し、似た名前のカテゴリ（例:「AI」があるのに「生成AI」）を安易に新規作成しないよう指示しています。新規カテゴリ候補は既存カテゴリの提案と区別して表示され、実際に追加するかはユーザーが選びます。

## 主な機能

- 新規作成（画面下部の「＋ 新規作成」ボタン、PCではCtrl+N）: 空のメモを作り、そのまま本文・カテゴリ・種類・お気に入り等を入力できる編集画面を開く（タイトル専用欄はなく、iPhone純正メモアプリと同様に本文1行目が自動的にタイトルになる）
- 自動保存: 入力後500ms操作がなければ自動保存（保存ボタンなし）
- カテゴリ（複数付与可・AND絞り込み対応）と「種類」（1メモにつき1つ）を別管理
- 未分類（カテゴリ0件）／あとで整理フラグ／お気に入り／ピン留め
- 編集履歴（一定間隔・大きな変更時に保存し、無制限増殖しないよう1メモ最大50件で自動整理）と復元
- 全文検索（タイトル・本文・カテゴリ名・種類名、リアルタイム）＋詳細絞り込み（AND条件）
- スマートビュー（検索条件の保存・呼び出し・編集・削除）
- 並び替え（作成日時・更新日時・タイトル・ピン留め優先）
- 複数選択による一括操作（カテゴリ追加/削除・種類変更・お気に入り・ピン留め・あとで整理・アーカイブ・ゴミ箱）
- アーカイブ／ゴミ箱（復元・完全削除）
- カテゴリ管理画面（作成・名前変更・削除。削除時は使用件数を警告し、メモ自体は削除しない）

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| Ctrl+K | 検索欄にフォーカス |
| Ctrl+N | 新規メモを作成して開く（画面下部の「＋ 新規作成」ボタンと同じ） |
| Esc | 開いているモーダル・複数選択モードを閉じる |

※ Ctrl+N 等はブラウザに「タブ」として開いている場合、ブラウザ自体のショートカットが優先されることがあります。気になる場合はブラウザの「このサイトをアプリとしてインストール」機能でインストールして使ってください。

## 仕様からの補足事項

- 当初は本文だけを入力してEnterで即保存する「クイック入力欄」を画面上部に常設していましたが、実際の利用を踏まえてユーザーの指示により廃止しました。現在は画面下部の「＋ 新規作成」ボタン（PCではCtrl+N）から、カテゴリ・種類なども含めて1つの編集画面で入力する方式に統一しています。
- タイトルもiPhone純正メモアプリに合わせて専用の入力欄を廃止し、本文欄（textarea）1つにまとめました。1行目が自動的にタイトルとして保存され（2行目以降が本文）、タイトルを別途意識して入力する必要はありません。
- 左メニューの「基本メニュー」と「標準スマートビュー」は項目がほぼ重複していたため、基本メニュー（すべてのメモ/未分類/あとで整理/お気に入り/ピン留め/最近作成/最近更新/アーカイブ/ゴミ箱）をナビゲーションの主軸とし、標準スマートビューは基本メニューに無い「今日作成」のみをスマートビュー欄の先頭に配置する形に統合しました。
- 種類（NoteType）の名前変更・削除は今回のバージョンでは未実装です（メモ編集画面から新規追加のみ可能）。カテゴリ管理画面は仕様通り実装済みです。
- 複数選択時の「カテゴリ追加」「カテゴリ削除」「種類変更」は、簡易的に入力ダイアログ（プロンプト）でカテゴリ名・種類名を指定する方式にしています。

## テストの実行方法

[tests/logic.test.html](tests/logic.test.html) をブラウザで開くと、絞り込み・並び替え・履歴保存ポリシーなどの純粋なロジックが正しく動くか自動でチェックされ、結果が画面に表示されます。データベースやUIの動作は、実際にアプリを操作して確認してください。

## バックアップについて

データはブラウザのIndexedDBにのみ保存されます。ブラウザのデータを消去する操作（「閲覧データの削除」等）を行うとメモも失われるため、重要なメモは定期的に別の場所へコピーしておくことをおすすめします。
